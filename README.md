# Jumia Nigeria E-commerce Web Scraping and Exploratory Data Analysis

## Project Overview

This project involves scraping product information from Jumia Nigeria's electronics category and performing Exploratory Data Analysis (EDA) to understand product pricing, categories, discounts, customer ratings and brand distribution.

The goal is to extract useful insights from e-commerce product data using Python.

## Objectives

- Collect product information from Jumia Nigeria.
- Clean and prepare the scraped dataset.
- Examine product price distributions.
- Identify categories with the highest product listings.
- Analyse discounts and customer ratings.
- Compare average product prices across brands.

## Tools and Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. **Data Collection:** Scraped product information from Jumia Nigeria using Requests and BeautifulSoup.
2. **Data Cleaning:** Checked missing values, duplicates, data types and inconsistencies.
3. **Exploratory Data Analysis:** Analysed product prices, categories, discounts, ratings and brands.
4. **Data Visualization:** Used histograms and bar charts to communicate findings.
5. **Insights:** Summarised the major patterns observed in the dataset.

## Key Findings

- The average product price was approximately ₦169,947, while the median was ₦74,500.
- Product prices were positively skewed, indicating that a few expensive products increased the overall average.
- Smart TVs had the highest number of listings among the categories examined.
- Split-System AC had the highest average category price at approximately ₦883,875.
- The average discount magnitude was approximately 42.88%.
- The average customer rating was approximately 4.06 out of 5.
- Canon Ink Cart had the highest average price among the brands with at least two product listings.

## Repository Contents

- `jumia_ecommerce_eda.ipynb` – Jupyter Notebook containing the scraping process, data cleaning, analysis, visualizations and findings.

## Conclusion

This project demonstrates how web scraping and exploratory data analysis can be used to collect, clean, analyse and interpret e-commerce product information.

It also provides practical experience in Python-based data collection, data preparation, analysis and visualization.
